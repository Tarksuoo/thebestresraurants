# Hongdae Eats

Tourist food map for Hongdae, Seoul. Static site: `index.html` + `data.js`, hosted on Netlify.

- Map: Naver Maps (falls back to OpenStreetMap)
- Reviews, accounts, photos: Supabase
- Restaurant data: data.go.kr, 소상공인시장진흥공단 상가(상권)정보 (2026-09)

`supabase/` holds the SQL that set up the database. It is not part of the website.
